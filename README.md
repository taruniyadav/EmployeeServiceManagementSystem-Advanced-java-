# Employee Service System

A simple Java project for managing employee details using JDBC and MySQL.

## Features
- View all employees
- Search for an employee by ID
- Apply salary increments
- Maintain increment history in the database

## Technologies Used
- Java
- JDBC
- MySQL
- Eclipse IDE

## Concepts Practised
- Classes, objects, and interfaces
- SQL queries and `PreparedStatement`
- Exception handling
- Database connectivity
- Transactions using commit and rollback

## About the Project
This project was developed as part of my Java learning journey to gain practical experience with database operations.

AI assistance was used to understand concepts, troubleshoot issues, and improve my understanding throughout the development process.
